## Manual verification boundary

The browser preview cannot provide a real soft keyboard, native crop UI, active Android/iOS lesson session lifecycle, physical magnetometer, or every government portal's live availability. Those flows need a signed-in Android/iOS device check. The app presents retry/error states rather than claiming that a government portal, native WebView, or local-unit profile is always available.
