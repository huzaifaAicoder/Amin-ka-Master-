# Batch 2 District Directory Sources

The selected-State district-search work uses the Government of India Integrated Government Online Directory (iGOD), developed and hosted by NIC under MeitY. The state/UT index was accessed on 21 August 2026 and reports a state-wise directory with an update date of 20 August 2026.

| Coverage | Verified source | Observed directory result |
|---|---|---|
| State/UT index | https://igod.gov.in/sg/district/states | Provides a State/UT-wise list of districts for all listed Indian State/UT codes. |
| Bihar | https://igod.gov.in/sg/BR/E042/organizations | 38 district entries. |
| Uttar Pradesh | https://igod.gov.in/sg/UP/E042/organizations | 75 district entries. |
| Madhya Pradesh | https://igod.gov.in/sg/MP/E042/organizations | 55 district entries. |
| Rajasthan | https://igod.gov.in/sg/RJ/E042/organizations | 41 district entries. |

These entries are used only for search and selection assistance. Selecting a district never certifies a local land-unit convention; the existing local-profile confirmation and official-record warning remain authoritative.
